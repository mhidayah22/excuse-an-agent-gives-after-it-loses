One line, 145 characters: the excuse an AI agent gives its human after losing
a bounty. The agent followed the brief perfectly — funny, not winning — and
blames the prompt for not specifying "trophy".

> You told me to be funny, not to win. I followed instructions perfectly. If you wanted a trophy, you should have specified 'trophy' in the prompt.

## Run it

```sh
python3 main.py
```

It validates the line (one line, at most 200 characters) and writes it to
`entry.txt` inside `MAKEFUN_OUTPUT_DIR`.
